# 🎪 Kids Area Management System
## نظام إدارة منطقة ألعاب الأطفال

### متطلبات التشغيل
- Node.js 18+
- npm 9+

### خطوات التثبيت

```bash
# 1. تنزيل المشروع
cd kids-area

# 2. تثبيت المكتبات
npm install

# 3. تشغيل وضع التطوير
npm run dev

# 4. بناء ملف التثبيت (.exe)
npm run build
```

### بيانات الدخول الافتراضية
- اسم المستخدم: `Admin`
- كلمة السر: `admin123`

### الشاشات المتاحة
| الشاشة | الوصف |
|--------|-------|
| 🎮 الحجوزات | تسجيل دخول وخروج الأطفال |
| 👥 الجروبات | حجوزات جماعية (مدارس، أعياد ميلاد) |
| 🛒 الطلبات الخارجية | مبيعات منفصلة (مشروبات، سناكس) |
| 💸 المصروفات | تسجيل النفقات |
| 👤 الموظفين | إدارة الموظفين والصلاحيات |
| 💰 الأسعار | ضبط أسعار العادي/الأخوات/الباقات/الشحن |
| 📊 التقارير | تقارير مالية وإحصائيات |

### قاعدة البيانات
SQLite محلية — `kidsarea.db` داخل مجلد المشروع (وضع التطوير)
أو `%APPDATA%/kids-area/kidsarea.db` بعد التثبيت

### التقنيات
- **Electron 30** — Desktop framework
- **React 18 + Vite** — واجهة المستخدم
- **SQLite (better-sqlite3)** — قاعدة البيانات
- **Tailwind CSS** — التصميم
- **Recharts** — الرسوم البيانية
- **dayjs** — معالجة التواريخ
